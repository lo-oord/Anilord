# Anilord design system

Anilord keeps Manga Peak's proven content and parser architecture while introducing a distinct visual language: deep ink surfaces, violet accent actions, rounded content cards, clear content-type chips, and short fade/slide transitions. The layout system is designed around discovery-first home sections, compact bottom navigation, search-first exploration, and focused details/player screens.

Mobbin references were requested for this task, but the connected catalog requires a paid Mobbin plan in the current environment. The implementation therefore uses an original design system rather than copying any proprietary screen, while preserving the requested interaction goals.
